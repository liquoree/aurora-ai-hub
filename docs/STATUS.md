4. **Вся команда:** AI-Заметки используют модель через AI Hub.

## Как обновлять после небольшого PR

1. Отметь `[x]` только завершённый и проверенный маленький пункт; крупные задачи остаются `[ ]` до полной готовности.
2. Если задача слишком большая, разбей её здесь на 2–4 конкретных подпункта.
3. При необходимости добавь рядом короткое уточнение: например, `— проверено в эмуляторе x86_64` или ссылку на Issue/PR.
4. Обнови дату **только если изменился реальный статус**. При PR без функциональных изменений укажи, что обновление `STATUS.md` не требуется.

Не отмечай работу других участников без их подтверждения. Этот файл описывает **проверенный прогресс**, а не количество коммитов.
