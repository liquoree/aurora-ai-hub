# Aurora AI Hub

Локальная платформа для работы с языковыми моделями на **ОС Аврора**. Цель: загрузить или импортировать GGUF-модель, запустить её на устройстве, общаться с ней в чате и предоставлять функции ИИ другим приложениям.

> **Статус: прототип.** Подтверждены сборка RPM, установка и запуск приложения в эмуляторе Aurora OS 5.2.1.200, наличие базовых QML-страниц. Работающий `llama-server`, инференс, загрузка моделей и межприложенческий API **пока не подтверждены**.

## Возможности (план)

- Каталог совместимых GGUF-моделей, скачивание и импорт локального файла.
- Управление локальным движком на основе `llama.cpp`.
- Чат с потоковой генерацией ответа.
- API для других приложений, демонстрация на AI-Заметках.
- Работа без облачного сервера после загрузки модели.

## Технологии

C++ / Qt 5, Qt Quick / QML, Sailfish Silica, Qt Network, CMake, RPM, Aurora SDK. Планируемый движок — `llama.cpp` / `llama-server`.

## Разработка и запуск

**Целевая среда:** Aurora OS **5.2.1.200**, комплект Aurora SDK **5.2.1.200 MB2**, целевая архитектура эмулятора **x86_64**. Для реальных устройств потребуется отдельная сборка под соответствующую архитектуру и тестирование.

1. Установите [Aurora SDK](https://www.omp.ru/sdk) с Aurora IDE, Build Engine и Emulator. [Общая инструкция](https://developer.auroraos.ru/doc/sdk/app_development/setup).
2. Клонируйте репозиторий: `git clone <URL_ЭТОГО_РЕПОЗИТОРИЯ>`.
3. Откройте корневой `CMakeLists.txt` в Aurora IDE.
4. Выберите комплект сборки **AuroraOS 5.2.1.200 x86_64** и настройте Build Engine / Emulator.
5. Нажмите **Ctrl+R** для сборки RPM, установки и запуска в эмуляторе.

### Windows

Следуйте [официальной инструкции для Windows](https://developer.auroraos.ru/doc/sdk/app_development/setup/setup_windows). Проверьте требования к виртуализации и необходимым компонентам. Для путей SDK и проекта лучше использовать латиницу без пробелов.

### Linux

Следуйте [официальной инструкции для Linux](https://developer.auroraos.ru/doc/sdk/app_development/setup/setup_linux). Для Aurora SDK 5.2.1 может требоваться Docker. Затем откройте `CMakeLists.txt` в Aurora IDE и выберите соответствующий kit.

### macOS

Следуйте [официальной инструкции для macOS](https://developer.auroraos.ru/doc/sdk/app_development/setup/setup_macos). Перед установкой проверьте поддержку вашей архитектуры Mac и версии SDK; работоспособность проекта на macOS командой пока не проверена.

> Исходный код предназначен для сборки через Aurora SDK, а не обычный настольный Qt. `git clone` сам по себе не устанавливает приложение на устройство. Готовые RPM для поддерживаемых архитектур могут публиковаться в GitHub Releases после тестирования.

## Структура

| Путь | Назначение |
| --- | --- |
| `qml/aurora-ai-hub.qml` | Корневое окно QML |
| `qml/modules/models/` | Экран установленных моделей |
| `qml/modules/catalog/` | Каталог моделей |
| `qml/modules/chat/` | Чат |
| `qml/modules/settings/` | Настройки и информация |
| `qml/shared/` | Общие QML-компоненты |
| `src/` | Точка входа C++ |
| `core/` | Планируемые ModelManager, RuntimeManager, AiClient |
| `integrations/dbus/` | Планируемый межприложенческий интерфейс |
| `examples/smart-notes/` | Планируемое демонстрационное приложение |
| `rpm/`, `icons/`, `translations/` | Пакетирование и ресурсы |
| `docs/STATUS.md` | Текущий прогресс |
| `docs/ROADMAP.md` | План разработки и распределение задач |
| `AGENTS.md` | Контекст и правила для AI-агентов |

Некоторые каталоги пока содержат только каркас или могут отсутствовать в конкретной ветке.

## Участие в разработке

Перед работой прочитайте [ROADMAP](docs/ROADMAP.md), [STATUS](docs/STATUS.md) и [AGENTS.md](AGENTS.md). Для изменений используйте отдельную ветку, GitHub Issue и Pull Request. В PR отмечайте результаты тестирования и обновляйте `docs/STATUS.md`, если изменился фактический статус функции.
